# ZIDE 🎨 - AN OPENSOURCE APPLICATION TO CREATE PIXEL ART

## What is ZIDE ?
**Zide** (abbr. Zide Is a Design Environment) is a cross-platform pixel art 
editor designed to provide artists with a minimalistic, easy-to-use interface. 
Whether you're creating a simple sprite or an intricate animation, Zide offers 
all the essential tools you need to bring your art to life.
